# KBB V Studio

抖音知识视频分析与创作工作台。

这个仓库包含两部分：

- `douyin_skill_workbench.html`：可视化工作台原型，展示样本分析、方法库、视频生产和 Codex 联动预览。
- `douyin-knowledge-video/`：可迁移到 Codex 或 Claude 项目的方法文件与参考资料。

## 两种工作模式

### 模式 A：样本分析与方法更新

分析视频、完整文案和账号数据，拆解整体叙事、局部文案与画面配合、声音、节奏和受众，判断新样本对现有方法是确认、补充还是修正。

### 模式 B：调用方法生产视频

使用已经验证的方法完成新主题的事实核验、标题、旁白、逐句分镜、声音设计、剪辑节奏和发布复盘方案。

## 使用方式

直接打开 `douyin_skill_workbench.html` 查看工作台原型。方法文件可以上传到 Claude Desktop 项目知识库，或放进 Codex 的 skills 目录中使用。

## 资料说明

仓库保留当前分析文档、生成脚本、抽帧资料和渲染结果，方便追溯方法的来源。原始视频如果后续加入，应注意 GitHub 单文件大小限制。
