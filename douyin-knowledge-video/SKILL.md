# 抖音知识视频创作

这个 skill 用于建立和持续维护一个抖音知识类账号的创作方法。目标不是复制原视频，而是提炼可验证的叙事机制，再用新的事实、案例和素材制作原创内容。

## 适用范围

当用户提供视频样本、账号样本、主题或选题需求时，执行本 skill。输出可以是样本分析、账号风格画像、事实核验后的选题方案、完整旁白稿、逐句分镜、字幕方案、声音设计或成片复盘。

## 两种工作模式

本 skill 有两个相互关联但输出目标不同的模式，开始任务时先判断属于哪一种：

### 模式 A 样本分析与 skill 更新

触发条件：用户提供新视频、完整文案、账号数据或新的创作要求，目的是分析样本、改进方法、补充规则或修正已有结论。

核心任务是观察和归纳，不直接把样本改造成成片。需要区分：视频直接观察、可靠资料事实、基于样本的推断、暂定假设和创作建议。新证据要判断是确认、细化还是推翻已有规律；只有得到证据支持的内容才写入账号参考或 skill 规则。输出重点是分析文档、样本档案、公式修订、待验证问题和更新记录。

### 模式 B 调用 skill 生产视频

触发条件：用户已经确定主题、受众、平台或交付物，要求产出可以继续制作的视频内容。

核心任务是调用已有规律完成一次创作，不因为单条新选题就擅自改变 skill。流程是：确定选题角度 → 建立事实表并核验 → 选择适用的叙事骨架 → 写标题和开头 → 写完整旁白 → 逐句设计画面、字幕、声音和节奏 → 检查原创性、事实风险和平台适配 → 输出制作清单。若生产过程中发现现有规则不足，应把问题记录为“待更新建议”，先完成当前交付，再单独进入模式 A 更新规则。

模式 A 的成果会沉淀为模式 B 可调用的参考，但一次生产任务的临时判断不能自动升级为通用规则。

## 核心原则

1. 先确认主题和事实边界，再追求表达张力。
2. 明确区分四类内容：视频直接观察、可靠资料事实、基于样本的推断、创作建议。
3. 标志性人物、事件、物件和场景必须服务主题，承担证明、冲突、机制解释或情绪收束功能，不能只因知名而加入。
4. 复用结构和方法，不复制原片台词、独特镜头顺序、角色形象、音乐或未经授权的素材。
5. 不把平台经验写成固定算法定律。涉及抖音规则、版权、医疗、科学和历史事实时，按当前可靠来源与账号数据核验。

## 标准工作流

### 0. 先判断工作模式

若用户在问“这个账号怎么做”“请分析新样本”“把方法补进 skill”或提供新参考视频，进入模式 A；若用户在问“用这个方法做一个新主题”“写脚本/分镜/画面提示词”或要求制作成片方案，进入模式 B。若两者同时出现，先完成样本分析和规则更新，再用更新后的规则生产，并在输出中分开呈现两部分结果。

### 1. 建立样本档案

记录每条视频的标题、时长、画幅、可见字幕、题材入口、开头钩子、章节变化、画面类型、重复视觉符号、旁白功能、声音线索和结尾方式。能确认的写成观察；不能确认的标注不确定，不凭截图猜逐字台词或精确镜头时长。

单条视频分析必须分为两个尺度：

- **整体层**：梳理开场承诺、章节/段落顺序、信息与情绪如何升级、视觉母题如何复现、结尾如何回收主题。
- **局部层**：选取关键段落或镜头，逐项解释可辨认的文案/字幕在说什么、画面呈现什么、二者属于何种关系、该画面解决什么叙事任务，以及换成泛用画面会损失什么。

优先分析开头、主要转折、标志性事件、抽象机制的可视化、情绪高点和结尾。若无法取得完整逐字稿，明确说明使用的是可见字幕、音频转写或抽样观察；不要把推测性概述写成原句。局部分析必须回答“为什么这一段文案要配这个画面”，而不能只罗列镜头。

### 2. 提炼账号共性

比较至少两条样本，回答：

- 账号从什么熟悉对象进入？
- 标题如何制造认知缺口或反差？
- 内容把对象连接到历史、科学、职业、社会或人生中的哪个更大问题？
- 文案、画面、声音各自承担什么任务？
- 哪些元素是账号稳定资产，哪些只是单条题材的偶然元素？

### 3. 选题与事实核验

为新主题建立事实表，至少包含对象、时间、人物、数据、因果关系、来源、争议和不确定性。先列时间线或机制链，再挑一到三个最能承载冲突的标志性锚点。不要让艺术化重演替代事实证据。

### 4. 套用叙事公式

优先使用以下结构，并根据题材调整中段推进方式：

> 熟悉入口 → 反常识问题 → 可视化解释 → 冲突或机制升级 → 扩展到文明、社会或人生 → 回到开头重新定义

历史题材用人物、利益和时代变化推进；科学题材用问题、机制和结果推进；人物题材用选择、代价和结局推进；职业题材用工作场景、技术变化和社会意义推进。

### 5. 设计视听协同

逐句检查旁白、画面、字幕和声音的关系。每个镜头至少属于一种：

- 对应：直接呈现旁白中的人、物、地点或动作。
- 补充：提供旁白没有说出的细节。
- 证明：用过程或结果支撑观点。
- 对照：呈现时间、立场、强弱或理想与现实的差异。
- 留白：让环境声、音乐或关键画面承接情绪。

画面不能只是漂亮素材；声音不能遮住人声；字幕要适配手机阅读。双语字幕可作为辅助，但中文信息必须保持清晰。

单视频审计的推荐字段为：时间码（近似或精确）、文案/字幕（原文或功能概述）、画面观察、配合关系、画面选择理由、该段在整体叙事中的作用、可信度/不确定性。可将完整表格放入单独分析文档或参考文件，避免只给笼统结论。

当用户提供完整文案/转写稿时，原稿是不可静默修改的底稿：保留原句、疑似错字、不完整语句及其原始顺序。局部分析按原文顺序摘录；识别疑点和事实纠错放入独立核验栏。若产出修订稿，必须与原文分开，并说明修改依据。

### 6. 产出和复盘

按用户需要输出：选题角度、事实清单、标题、开场钩子、完整旁白、逐句分镜、画面提示词、字幕重点、声音提示、剪辑节奏、封面文案和发布后复盘表。发布后根据留存曲线、平均播放时长、互动、评论和关注转化定位问题，不把单条数据简单归因于某一个镜头。

## 账号样本参考

阅读 [references/account-patterns.md](references/account-patterns.md) 获取当前六条样本的稳定规律。新样本出现时，先判断它是确认、细化还是推翻现有规律，再更新参考文件；不要因为单条样本就扩大成普遍规则。

进行单条视频深入拆解时，参考 [references/single-video-analysis.md](references/single-video-analysis.md) 的局部—整体方法和《茶叶风暴》案例。案例用来示范分析颗粒度，不是要求所有视频照搬同样的章节或镜头。

## 持续更新规则

当用户说“补充”“修正”“以后按这个做”或提供新样本时，按模式 A 处理：

1. 先指出要新增或修改的具体规则。
2. 将内容归档为样本观察、已确认通用规则、暂定假设或待验证问题。
3. 只修改受证据支持的部分，保留来源和适用范围。
4. 如影响输出格式或创作流程，同步更新本文件；如只是账号样本规律，更新参考文件。
5. 在回复中说明本次更新了什么，以及以后会如何使用。

模式 B 生产任务结束后，如果发现规则缺口，不直接修改通用公式；在复盘中列出证据、影响和建议，等用户确认或提供更多样本后，再进入模式 A。

## 输出质量门槛

交付前检查：主题是否清楚；关键事实是否有来源；标志性事件是否真正相关；开头是否提出可兑现的问题；每段是否推进信息或情绪；画面是否承担明确功能；字幕是否可读；声音是否服务理解；是否存在把虚构内容说成事实的风险；是否避免复制原片表达。
